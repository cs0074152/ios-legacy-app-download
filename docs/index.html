05 / GOOD TO KNOW

开始前，
你可能想知道。

明确能力，也说明边界。
让每一步都有可靠的预期。

这是一个一键下载软件吗？+

这是一个 Agent Skill 与中文使用指南，页面用于介绍项目。查询和下载由上游 ipatool 完成，没有内置桌面客户端或托管下载服务。

所有 App 的历史版本都能下载吗？+

不能保证。应用是否仍提供下载、账号是否拥有许可，以及商店地区和 Apple 服务状态都会影响结果。网页有更新记录，也不代表该版本一定可下载。

下载的 IPA 可以直接安装吗？+

下载成功与安装成功需要分别验证。包通常带 FairPlay 加密，普通重签不会自动解密；账号许可、设备系统、架构和安装工具支持情况也会影响结果。请先备份并确认安装方案，再决定是否删除当前版本。

我的账号信息会发送到哪里？+

本仓库没有收集账号的服务端，介绍页面也不接收账号信息。实际登录由 ipatool 与 Apple 通信，并按上游实现保存本地会话。密码、验证码和会话文件都应保密。

只记得大致时间，可以开始查吗？+

可以用目标地区 App Store 页面展示的更新记录缩小范围，再核对版本元数据。网页记录可能不完整，日期来源也需要交叉核对。
